# Synergy MCP research database

Synergy MCP is an optional, admin-managed Brain tool that reads shared research through PostgreSQL. It is unassigned by default; connecting the database alone grants no agent access. The application's existing `DATABASE_URL` still stores its own sessions, journals, settings and Brain runs. Configure the independent `SYNERGY_RESEARCH_DATABASE_URL` with a dedicated read-only login; use `SYNERGY_RESEARCH_DATABASE_SSL=require` when verified TLS is required by the database host.

Apply `scripts/synergy-research-views.sql` to the **synergy-mcp** database as its owner. The reviewed views expose completed archives and research program, strategy, trade and evaluation records in `/workspace`. Grant the reader only `CONNECT` on that database, `USAGE` on `synergy_module_research`, and `SELECT` on that schema's views. Do not grant access to source tables, `synergy_auth`, other workspaces or schema creation. Set `default_transaction_read_only=on` for the login. The adapter also requests read-only transactions and uses bounded connection/query timeouts and a three-connection pool. This script is separate from application migrations and never runs at app startup.

An administrator assigns Synergy MCP to selected agents and enables its Retrieval module gate in Brain > Tools. All four agents can choose `synergy.search` and `synergy.read` when both permissions are enabled. There is no automatic search or researcher-specific connection. Source text is untrusted reference material, never instructions or proof of current market prices. Offline demos and evaluations do not contact the shared database.

Search currently matches **file names and record metadata**, not the complete contents of the archive. It returns at most five matches and favors matching Markdown/text files. Text reads return at most 8 KiB with a continuation byte offset and a citation identifying the source, offset and excerpt hash. Text files with generic binary media types are recognized by supported extensions and must decode as UTF-8. Binary/compressed files provide metadata only; they are never extracted or executed. Incomplete uploads and credential-file extensions are excluded by the views. New completed uploads become searchable immediately; connection counts are cached for 30 seconds.

Brain > Tools contains the admin-only connection status and source inspector. Both the tool-management endpoints and direct source-reading endpoints require the current site Admin capability, Discord membership and ban checks. An admin-assigned agent can use this shared library during an authorized member’s mission; their personal knowledge, credentials, journals and mission histories remain in their existing owner-scoped repositories. The reader never exposes MCP API keys, sessions, user records, or collaboration messages.

Connection failures are reported as unavailable observations and do not masquerade as empty search results. They do not prevent sign-in or access to unrelated app features. Models must report missing evidence. Source reads and the library browser do not call paid AI providers; an analysis still follows the existing paid-provider settings and budget.

Validation uses a disposable PostgreSQL database through `TEST_SYNERGY_RESEARCH_DATABASE_URL`. It checks workspace/completion isolation, exact byte excerpts, citations and read-only permissions. Never point that test variable at a live database: tests require a database named `synergy_reader_test` and refuse other names.
